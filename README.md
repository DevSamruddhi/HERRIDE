# HERRIDE 🚖 - Women’s Cab Booking Platform

HERRIDE is a secure and user-friendly cab booking system built to prioritize women’s safety and convenience. It includes features for user registration, login authentication .

---

## 🔍 Features

- 🧍‍♀️ Women-only user and driver support
- 🚗 Car and driver registration
- 💳 Payment gateway integration
- 🔔 Real-time notifications
- 🔐 Secure login and role-based access (Admin, Driver, User)
- 📊 Admin dashboard with user, driver, and payment analytics

---

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, Bootstrap *(or any other)*
- **Backend**: Django (Python)
- **Database**: PostgreSQL
- **Other tools**: Git, GitHub, OneDrive, etc.

---

## 🚀 How to Run Locally

```bash
# Clone the repo
git clone https://github.com/DevSamruddhi/HERRIDE.git

# Navigate to the project folder
cd HERRIDE

# Create a virtual environment (optional but recommended)
python -m venv myenv
myenv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run migrations
python manage.py makemigrations
python manage.py migrate

# Start the development server
python manage.py runserver
